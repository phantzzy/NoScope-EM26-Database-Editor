# Changelog

All notable public changes to NoScope are documented in this file.

## [v2.1.1 Hotfix] - 2026-07-24

### Hotfix Summary

- Fixed `.emdb` saving regressions that could produce game-incompatible databases.
- Fixed merge handling so incoming database changes preserve the fields the game expects.
- Fixed team editor controls that were still behaving like plain text fields.
- Improved validation for duplicate people, duplicate teams, and invalid team assignments.
- Added a Ukrainian support badge to the header.

### Saving and Merge

#### Fixed

- Fixed save normalization for team fields so edited databases remain compatible with the game.
- Fixed merge behavior around team identity fields, player assignments, and record matching.
- Improved preservation of game-sensitive CSV field names and values when saving edited `.emdb` files.

### Team Editor

#### Fixed

- Moved `ERS`, `Academy`, `BGColor`, `StartIGL`, `FPMap`, `FBMap`, and `Disbanded` into the Team Identity editor.
- Changed `BGColor` to use a color picker with a visible swatch and editable hex code.
- Changed `Academy` to use team search instead of free text.
- Changed `StartIGL` to use a player search limited to players assigned to the current team.
- Changed `FPMap` and `FBMap` to use fixed map dropdowns.
- Changed `Disbanded` to use a Yes/No segmented switch.
- Improved dropdown alignment for map selectors.

### Validation

#### Fixed

- Duplicate validation now only flags exact duplicate values instead of fuzzy matches.
- Added duplicate staff name checks.
- Added duplicate player name checks.
- Added player-versus-staff name checks for people who appear in both tables.
- Added validation for players assigned to a non-existent team.
- Non-existent team assignments now appear as red invalid warnings.
- Duplicate warnings now use yellow warning styling.

### Interface

#### Added

- Added a Ukrainian heart badge and support message beside the Steam and Discord links.
