# Changelog

All notable public changes to NoScope are documented in this file.

## [v2.2.0] - 2026-07-25

### Release Scope

- This release mainly applies to the new NoScope desktop app and installer.
- The browser/static build remains available, but several v2.2.0 features depend on the Electron desktop runtime.

### Desktop App

#### Added

- Added a standalone Electron desktop app for NoScope.
- Added native `.emdb` open and save dialogs.
- Added a custom frameless NoScope title bar with native minimize, maximize, and close controls.
- Added desktop file access support for saving player, staff, team, sponsor, and tournament images into the game `CustomAssets` folders.
- Added configurable CustomAssets folder selection for users whose game files are stored outside the default location.
- Added `Paste image` support in entry image editors for saving copied clipboard images as `.png` files.
- Added `Open folder` and `Choose folder` actions for CustomAssets workflows.

### Installer

#### Added

- Added a fully custom NoScope Windows installer.
- Added a matching custom NoScope uninstaller.
- Added NoScope branding, custom window controls, custom shortcut options, and NoScope icons across installer, uninstaller, app shortcuts, and app metadata.
- Added per-user installation with Start menu and desktop shortcut creation.

#### Changed

- Renamed the generated installer to `NoScope-Installer.exe`.
- Replaced the default Windows installer wizard styling with NoScope red, black, and gray styling.
- Removed the standard Windows title bar from the installer, uninstaller, and app window.
- Improved installer layout so bottom actions no longer clip outside the installer window.

### Assets

#### Added

- Added Cloudflare Pages remote asset manifest support.
- Added remote image lookup from `https://noscope-assets.pages.dev/manifest.json`.
- Added remote image loading for player, staff, team, sponsor, and tournament assets.
- Added local remote-image caching so successfully loaded remote images can be reused by the desktop app.
- Added game-folder-first image lookup for `AppData\LocalLow\NeuronaGames\EsportsManager\CustomAssets`.

#### Changed

- Removed bundled `assets/custom` images from the packaged desktop installer.
- Reduced installer size by loading the large custom image library from the game folder, remote asset host, or local remote cache.
- Updated sponsor image lookup to prioritize numeric sponsor identifiers such as `num`, `id`, `sponsorid`, and `internalid`.

### Image Workflow

#### Added

- Added direct clipboard image saving from copied browser images.
- Added automatic `.png` naming for pasted images.
- Added visible saved-path feedback after image paste actions.
- Added custom NoScope-styled error dialogs for failed image URL downloads and failed paste actions.

#### Fixed

- Fixed pasted image filenames receiving duplicate extensions such as `.png.png`.
- Fixed image save locations being unclear after paste actions.
- Fixed sponsor cards failing to resolve numeric sponsor logo files.
- Fixed app and installer icon handling so NoScope icons are used instead of default Electron icons.

### Remote Assets

#### Added

- Added support for remote manifests generated from the external NoScope assets repository.
- Added runtime lookup against remote manifest keys and direct Cloudflare Pages image URLs.
- Added compatibility for `Staff` and `Staffs` CustomAssets folder naming.

### Merge Beta

#### Changed

- Temporarily disabled Merge Beta while database safety issues are being fixed.
- Changed the toolbar label to show the merge feature as paused.
- Prevented the merge modal from opening while the feature is disabled.

### Known Limitations

- Remote image loading requires an internet connection until images have been cached locally.
- Merge Beta is intentionally unavailable in this release.
- The installer is focused on Windows desktop distribution.
