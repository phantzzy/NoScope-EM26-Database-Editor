# Changelog

## [v3.0.0 Beta 2 App] - 2026-10-30

Beta 2 focuses on safer merges, clearer review feedback, restored CustomAssets image saving, and additional guardrails around unsupported database content. This remains a beta build: keep your original databases backed up and save edits under a new filename until in-game testing is complete.

### Merge safety and performance

- Prevented a different internal player ID from automatically creating a duplicate when strong identity details match an existing player.
- Highlighted suspicious player matches, displayed both IDs, and required manual approval before applying them.
- Added counted review filters for manual-review items, ID mismatches, identity changes, and safe changes.
- Treated nickname-only collisions as conflicts and rechecked additions while applying a merge to block duplicate aliases.
- Added post-merge health checks for suspicious player identity pairs already present or newly created.
- Fixed cached merge-index updates when additions and updates are applied in the same operation.
- Kept large merges responsive with incremental duplicate indexes, chunked application, and visible progress feedback.
- Added the same full-screen progress feedback while building the merge review.

### Images and warnings

- Restored saving chosen player, staff, team, sponsor, and tournament images into their correct game `CustomAssets` folders.
- Renamed saved images using the category-correct identity and filename syntax.
- Recognized sponsor `Num` and `CompanyName` when saving, pasting, previewing, or downloading sponsor images.
- Replaced native image identity, URL, and file-type alerts with NoScope-styled warning dialogs.
- Added a custom warning when attempting to create more than the game's default limit of 51 tournaments.
- Added a dedicated validator warning for imported databases containing more than 51 tournaments while retaining an explicit **Save anyway** confirmation.

### What's New and documentation

- Added a version-aware What's New popup that opens automatically after an update with the current release expanded.
- Added a **Don't show this again until the next NoScope update** option that is stored separately for each version.
- Kept the full release archive available from the What's New button after automatic display is dismissed.
- Added a complete feature catalogue and a development roadmap focused on optimization, clarity, file-size reduction, testing, and maintainability.
- Updated app, installer, package, documentation, and release metadata to `v3.0.0-beta.2`.

### Verification

- Added regression coverage for the version-aware What's New preference and synchronized Beta 2 version labels.
- Tested tournament-limit creation blocking and over-limit save confirmation.
- Verified image folder and filename behavior for players, teams, staff, sponsors, and tournaments.
- Rechecked the complete Electron workflow with the developer `default.emdb` and the supplied 52-tournament `noscope.emdb`.
- Rebuilt and verified all five installer-bundled offline Library databases.
- In-game import and playthrough testing remain pending.
