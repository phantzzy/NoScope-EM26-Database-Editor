# Changelog

All notable public changes to NoScope are documented in this file.

## [v2.3.0 Webpage] - 2026-07-26

### Release Scope

- This release applies to the NoScope web version.
- Desktop-only actions are now hidden on the webpage while shared editor, merge, validator, changelog, and remote asset features remain available.

### Web Experience

#### Changed

- Hid desktop-only controls in the web build, including updater, native game-folder asset actions, and Cloudflare asset installation.
- The changelog panel now detects the browser build and opens the Webpage changelog by default.
- Added a GitHub header link beside Steam and Discord.
- Improved light-mode contrast for the Ukrainian support badge.
- Replaced the empty-state emoji folder with a styled SVG folder icon.

### Changelog

#### Added

- Added App and Webpage tabs to the changelog panel.
- Split desktop app release notes from web release notes.

### Remote Assets

#### Changed

- The web version continues to load available images from the Cloudflare asset library.
- Added a direct link to the `phantzzy/NoScope-Assets` GitHub repository from the Assets panel.
- Added support for player images keyed by internal ID, reducing nickname collisions for players with the same display name.

### Remote Databases

#### Changed

- The Library and Load Default DB flows now load database packages from the Cloudflare remote library when available.
- Database packages no longer need to ship inside the web bundle.

### Merge

#### Changed

- Re-enabled Merge and removed the disabled/beta toolbar tag.
- Changed merge updates so existing values are preserved unless the incoming database has a real replacement value.
- Improved merge review decisions so choosing a conflict option keeps the review UI visible.
- Improved merge result spacing and report layout.

#### Fixed

- Blocked risky blank overwrites during merge.
- Blocked internal ID changes for existing records.
- Reduced unnecessary merge churn by ignoring unchanged or empty incoming values.

### Validation

#### Added

- Added a richer validator review flow with duplicate grouping, searchable findings, filters, and expandable issue cards.
- Added record actions inside validation findings, including edit and delete.
- Added custom confirmation dialogs for destructive validator actions.
- Added a rerun validation action so fixed or deleted records disappear from the current report.
- Added hover previews for linked records in validation findings.

#### Changed

- Renamed unclear validation wording around affected tables to better explain affected database sections.
- Improved validator footer layout so rerun and close actions are easier to reach.
- Improved sticky validation headers so scrolled content no longer shows visual gaps behind them.

### Editors

#### Added

- Added required-field checks before saving player, staff, team, sponsor, and tournament records.
- Added custom missing-field messaging instead of relying on browser validation popups.
- Added explanatory tournament CupID guidance.
- Added sponsor guidance explaining that sponsor logos do not appear on in-game shirts.
- Added a FACEIT skill helper with Base, High, and Elite Level 10 ELO presets.
- Added tier guide panels and similar-profile previews to the player skills editor.

#### Changed

- Tuned FACEIT-generated stats to sit between T4/T3, T3, and T3/T2 depending on ELO level.
- Replaced the old T1/T2/T3/T4/NN skill preset markers with badge images.
- Kept the FACEIT ELO dropdown aligned separately so enabling it no longer shifts the preset buttons.
- Improved player-card stat panel sizing and name line-height to avoid clipping.
- Updated dropdown hover styling to use NoScope red.

### Loading

#### Changed

- Database loading now waits for visible card images to finish loading before hiding the loading screen.
- Replaced visible browsing-card `No image` flashes with a neutral image placeholder.

### Known Limitations

- Desktop-only features require the NoScope desktop app.
- Remote images require network access until already cached by the browser.
