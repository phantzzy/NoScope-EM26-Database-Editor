# Changelog

## [v3.0.0 App] - 2026-10-27

Welcome back to NoScope! It's been a while, and the game has kept moving forward. Version 3.0.0 brings the editor up to date while keeping the tools you know for building and fine-tuning your databases. Thanks for your patience—it's good to have you back. Let's get editing!

### Database compatibility

- Updated compatibility with the supplied October 2026 developer database.
- Added Anubis and Cache to all six team map preference selectors.
- Added tournament tiers 3 and 4, a female-team toggle, and AWPer role selection.
- Preserved unfamiliar dropdown values and existing boolean encodings when records are opened.
- Kept FACEIT profile links separate from origin flags and badges.
- Exposed Staff HLTV and Liquipedia fields.
- Allowed blank tournament locations while validating supplied country/city combinations.

### Rosters and saving

- Applied saved roster order consistently to team cards, lists, and the roster editor.
- Saved main-squad and bench ordering, and maintained references through player ID edits, transfers, deletion, and merge undo.
- Preserved unknown archive files, unknown CSV columns, and unchanged table contents during saving and export.
- Prevented roster data from leaking between opened databases.
- Rejected malformed or unsupported files before replacing the active database.
- Added validator findings for unresolved roster references without guessing replacement identities.

### Verification

- Added package and Electron regression suites covering compatibility and existing editor workflows.
- Verified encrypted save/reopen behavior across all 7,188 records in the supplied database.
- Retained Rating, manual/automatic Potential, comparison, mass editing, and reviewed merge/undo behavior.
- In-game import and playthrough remain unverified. The supplied database contains unresolved roster references and missing values that the validator reports.
